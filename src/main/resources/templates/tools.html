JS modules of the javascript tool

A module is bound for one script call, so a switch takes effect from the next call - a script that is already running keeps its modules. The switch is process-wide (one javascript tool, one sandbox policy). The tool description is built at start-up and is not rewritten: a switched-off module answers require('x') with "Cannot find module", and that message names the modules that are bound. Modules switched off by the configuration (e.g. -Dmcp2sdk.module.git.enabled=false) are not listed here - they are absent, not off, and cannot be switched on at runtime. shipped is one block: the libraries of js/tools/modules.json load each other.
